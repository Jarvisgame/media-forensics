# 00 · 开发方案（8 周 · 业余单人版）

> **参数**：单人开发 · 业余投入 1~2h/天（均值 1.5h）· 无比赛/立项硬性交付要求
> **总量**：约 80 小时（含缓冲），校准为「精简底线档」
> **原则**：经典算法替代训练 · 公开权重替代自研模型 · 优先序砍单替代延期承诺

---

## 1. 交付物定义（v0.5 本地单机版）

### 5 项分析能力

| 能力 | 说明 | 计划周 |
|---|---|---|
| 元数据/容器取证 | EXIF、缩略图不一致、结构异常、时间线矛盾 | W1 |
| 信号痕迹 | ELA、噪声残差、双压缩估计 | W2 |
| copy-move 定位 | 关键点 + 聚类，像素级区域 | W3 |
| AIGC 鉴别基线 | 真实 vs 生成（公开权重推理，不训练） | W5 |
| 对抗清洗鲁棒矩阵 | 重压缩/缩放/截图/噪声 批量压测 | W7 |

### 3 项工程骨架

- 证据链留痕：哈希链 + 案件库（SQLite）
- 三态判定与证据包：未见异常 / 无法判定 / 疑似 + HTML 报告
- golden set 评测体系：自建集 + 公开子集 + 指标脚本

### 1 个入口

CLI 为主，W8 加 Gradio 薄界面。

### 硬线（任何砍单都不移除）

**确定性输出 · 版本锁定 · 全留痕** —— 沿用签名核验项目的质量门/三态/留痕模式。

架构详见 `01-系统架构.md`；评测口径详见 `02-评测协议.md`。

## 2. 不做清单（时间红线）

任何模型训练 · 视频/音频通道 · 生成模型归因 · 司法认定宣称 · 平台化（并发/多租户）。
以上归入「9 周后延伸清单」（见 §7）。

## 3. 8 周排期

| 周 | 主题 | 任务包与工时 | 验收标准 |
|---|---|---|---|
| W1 | 骨架+证据链 | 环境/仓库 1.5h；数据模型+SQLite+哈希链 2.5h；插件协议+CLI 2.5h；元数据模块 2.5h | `analyze 样例图` 生成案件记录+JSON 报告+留痕 |
| W2 | 信号痕迹 | ELA+热图 2h；噪声残差 2h；双压缩估计 3h；集成 2h | 单图输出 3 张痕迹热图+初步分数 |
| W3 | copy-move | 关键点+匹配 3h；聚类+区域后处理 3h；误报控制 3h；集成 1h | Columbia 子集+自备样例可检出 |
| W4 | 评测+检查点 | golden set 30~50 张 2.5h；指标脚本 3h；差缺修复 2h；复盘调档 1.5h | 定位指标跑通；决定后续砍单 |
| W5 | AIGC 基线 | 选型+权重 2.5h；推理集成 2.5h；测试子集+AUC 3h；接入融合 1h | 受控子集有 AUC 数字 |
| W6 | 融合+报告 | 归一化+融合 3h；三态阈值 1.5h；证据包+HTML 报告 4h；回归 1.5h | 端到端出三态结论+报告 |
| W7 | 对抗实验室 | 清洗流水线 3h；批量矩阵 3h；可视化+调参 3h | 清洗前后衰减曲线 |
| W8 | 收口 | Gradio 2.5h；文档 3h；冷启动复现 2h；演示材料 1.5h | 新机器一键复现 demo |

合计约 74h，留 6~10h 缓冲。

> ⚠️ 风险最高两周：**W3（调参）与 W6（集成）**，超时即触发 §4 砍单规则。

## 4. 优先序与砍单规则

| 级别 | 内容 | 规则 |
|---|---|---|
| P0 必保 | W1+W2 全部、融合三态简版、最小 golden set（20 张）、冷启动复现 | 任何情况不砍 |
| P1 重要 | copy-move、对抗矩阵（3 种基础清洗）、AIGC 基线集成、HTML 报告 | 紧张时降级为脚本+文档 |
| P2 加分 | copy-move 深度调参、跨生成器扩展、Gradio UI、文档美化 | 第一个被砍 |

- 若实际只有 1h/天（7h/周，总量约 56h）：砍掉全部 P2 + P1 尾部，系统仍完整可演示。
- 若进度超前（stretch）：视频抽帧通道（~5h）、再生攻击测试（~3h）、自训小模型（~10h+）。

## 5. 资源与数据

- **无 GPU 可行**：经典算法纯 CPU；AIGC 基线选 ResNet 级小模型做 CPU 推理（单图秒级）
- **数据**（W1 完成落盘）：CASIA v2（~2GB）、Columbia（小）；AIGC 用 CNNDetection/UniversalFakeDetect 测试子集各 200~500 张（避开 GenImage 全量级下载）
- **golden set**：30~50 张自建（真实拍摄/社交转存/截图/重压缩/篡改/AI 生成），JSON 标注（见 `02-评测协议.md` §1.1）
- **工具**：Python 3.11（conda 环境 `media-forensics`）+ OpenCV + Pillow/ExifTool + SQLite + Gradio + PyTorch（仅推理）

## 6. 验收标准（8 周「成功」的定义）

1. 对 1 张真实图、1 张篡改图、1 张 AI 生成图，同一脚本输出三态结论 + 证据包 + HTML 报告
2. 有三组数字：golden set 指标、Columbia 子集定位指标、清洗前后衰减表
3. 任一历史分析可通过哈希链校验脚本追溯
4. 新机器 clone → 一键脚本 → 复现演示

## 7. 9 周后延伸清单

- 视频抽帧通道（复用图像栈）
- 自训/精调篡改定位模型
- 再生攻击（扩散 img2img）对抗实验
- 生成模型闭集归因
- 笔迹/文档鉴定模块接入（复用既有资产）
- API 服务化

## 8. 执行习惯（业余节奏）

- 开工先看任务卡，收工更新任务卡——碎片时间最怕重新想「上次做到哪」
- 大块时间（周末 ≥3h）安排集成/评测类任务；工作日碎片安排调参/文档/修小 bug
- 每完成一项立即提交 + 一行 changelog；模型、配置、随机种子全部锁定进仓库
- AI 可加速样板与调试，算法决策与验收自己把关（三条硬线不外包）
- 每周日 30 分钟复盘 + 排下周任务卡；**连续 3 天推不动就执行砍单**
