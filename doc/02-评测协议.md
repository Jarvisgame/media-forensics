# 02 · 评测协议

> **纪律**：先协议后实现；测试集不参与调参；指标照实报告（含不好看的部分）。

## 1. 评测集

### 1.1 golden set（自建，30~50 张）

| 类别 | 数量（建议） | 说明 |
|---|---|---|
| 真实拍摄 | 8~10 | 手机相机直出 |
| 社交转存 | 6~8 | 微信/微博转存（验证 EXIF 被剥离场景） |
| 截图 | 4~6 | 屏幕截图、文档截图 |
| 重压缩 | 4~6 | 已知质量档重压缩 |
| copy-move 篡改 | 6~8 | 自造（复制区域），附 mask |
| 拼接篡改 | 4~6 | 自造（跨图拼接），附 mask |
| AI 生成 | 6~8 | GAN/扩散各半 |

标注 schema（`data/golden/labels.json`）：

```json
{
  "id": "g-0001",
  "label": "tampered",
  "tamper_type": "copy_move",
  "mask": "masks/g-0001.png",
  "source": "self",
  "notes": ""
}
```

- `label`：`authentic` | `tampered` | `ai_generated`
- `tamper_type`：`copy_move` | `splicing` | 空
- 划分：dev / holdout ≈ 60/40（holdout 只在 W7~W8 揭盲）

## 2. 指标定义

### 2.1 图像级（二分类）

Precision / Recall / F1 / Accuracy；AIGC 另报 AUC。

### 2.2 定位级（有 mask 的篡改样本）

mask 二值化规则：模型/算法分数 ≥ 0.5 且最小区域面积 ≥ S（S 在实现周登记）。

- 像素级 Precision / Recall / F1
- IoU@0.25 / IoU@0.5（区域命中率）

### 2.3 鲁棒性矩阵

清洗链（每项独立应用 + 组合）：

| 清洗 | 参数档 |
|---|---|
| JPEG 重压缩 | Q=95/85/75/65 |
| 缩放 | 0.5x / 0.25x |
| 裁剪 | 边缘 10% |
| 截图模拟 | 屏幕渲染 → 再编码 |
| 高斯噪声 | σ=2/5 |

输出：清洗 × 指标 的衰减表与曲线（PNG + CSV）。

### 2.4 泛化

跨生成器 ΔAUC = 受控集 AUC − 留出生成器 AUC。

## 3. 三态判定规范

- 分数映射：各迹分数经 dev 集校准 → [0, 1]
- 阈值（初定经验值，W6 用 dev 集校准）：`lo = 0.35`，`hi = 0.65`（暂定）
  - `score < lo`：**未见异常**
  - `lo ≤ score ≤ hi`：**无法判定**（列明各迹矛盾点）
  - `score > hi`：**疑似**（附完整证据包）
- `margin = |score − 最近阈值|`，作为置信度表达之一
- 冲突规则：任一痕跡与其余显著冲突时，强制「无法判定」并列出矛盾证据

## 4. 报告格式

- `report.json`：结论 + 各迹分数 + findings + artifacts 索引 + 版本信息
- `report.html`：人读版（热图内嵌）
- `metrics.csv` + `curves/*.png`：批量评测输出
- 元信息必含：code_version、模型 SHA-256、数据哈希、评测日期
