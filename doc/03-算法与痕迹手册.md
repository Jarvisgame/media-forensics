# 03 · 算法与痕迹手册

> 随开发进度填充：每个痕迹一节，记录原理、工程化参数、输出与局限。
> 状态标记：⬜ 待实现 / 🟡 进行中 / ✅ 完成

## 3.1 元数据/容器取证（W1 · ⬜）

**检查项**

- EXIF 字段：设备、拍摄时间、软件字段（Photoshop/GIMP/美图等）、修改时间
- 缩略图与主图不一致（EXIF 内嵌缩略图 vs 主图差异）
- 结构异常：JPEG 段顺序/多余 APPn 段、PNG 块异常
- 时间线矛盾：EXIF 时间 vs 文件修改时间 vs GPS 时区

**工程要点**

- 主用 ExifTool 的 JSON 输出（规则表驱动，每条规则独立 Finding）；piexif 兜底
- 规则宁可「记录痕迹」不轻下结论：社交平台会重写/剥离元数据

**输出**：findings 列表（规则 ID、证据字段、严重度）

**局限**：无 EXIF ≠ 伪造；软件痕迹 ≠ 篡改

## 3.2 ELA（W2 · ⬜）

- **原理**：整图按固定质量（暂定 Q=90）重压缩，与原图差分并经放大系数可视化
- **输出**：热图 artifact + 分块统计特征
- **局限**：对整图多次压缩普遍敏感（无定位力）；阈值需按图自适应（对比度归一化）
- **定位用法**：热图只作线索；二值化阈值进评测协议统一口径

## 3.3 噪声残差（W2 · ⬜）

- **原理**：高通核（SRM 子集/高斯差分）提取传感器噪声，拼接区与背景噪声统计不一致
- **输出**：残差图 + 分块方差统计
- **局限**：重压缩/降噪破坏残差；与 ELA 互补

## 3.4 双压缩估计（W2 · ⬜）

- **原理**：估计 JPEG 量化表（比对标准表/直方图法）；重压缩响应（多质量档重存后 blockiness 极小值）
- **输出**：疑似双压 Q 对 + 响应曲线
- **局限**：仅对 JPEG 有意义；单压图可能误报

## 3.5 copy-move 定位（W3 · ⬜）

- **流程**：SIFT/ORB 关键点 → 匹配（KNN + ratio）→ 空间聚类（排除近邻/同坐标）→ 区域生成（凸包 + 形态学）→ 后处理
- **误报控制**：弱纹理区过滤、均匀重复纹理排除、最小区域面积、位移距离阈值
- **输出**：mask + 匹配对可视化
- **局限**：缩放的 copy-move 困难；对强压缩敏感

## 3.6 AIGC 鉴别（W5 · ⬜）

- **方案**：公开权重推理（候选：CNNDetection 系 ResNet-50；UniversalFakeDetect CLIP 系），预处理严格对齐训练（resize/center-crop）
- **输出**：概率 + 权重 SHA-256
- **局限**：跨生成器泛化差 → 以评测协议呈现泛化差距，结论一律三态
- **纪律**：不训练；许可登记（`doc/04`）

## 3.7 融合与三态（W6 · ⬜）

- **归一化**：各迹分数 → [0, 1]（先经验映射；W6 用 dev 集拟合轻量映射）
- **融合**：v0 规则（加权 + 冲突检测）；v1 轻量逻辑回归（4~8 维特征，系数可解释）
- **三态**：`lo/hi` 阈值 + margin；冲突时强制「无法判定」并列出矛盾证据
