# 数字媒体取证分析系统（media-forensics）

本地单机版数字媒体取证分析系统 v0.5 —— 面向图片的「多迹分析 + 三态判定 + 证据链留痕」。

> 状态：脚手架阶段（W0）。8 周业余开发计划见 `doc/00-开发方案.md`。

## 目标能力（v0.5）

| 能力 | 说明 | 计划周 |
|---|---|---|
| 元数据/容器取证 | EXIF、缩略图不一致、结构异常、时间线矛盾 | W1 |
| 信号痕迹 | ELA、噪声残差、双压缩估计 | W2 |
| copy-move 定位 | 关键点 + 聚类，像素级区域 | W3 |
| AIGC 鉴别基线 | 真实 vs 生成（公开权重推理，不训练） | W5 |
| 对抗清洗实验室 | 重压缩/缩放/截图/噪声 批量压测 | W7 |
| 融合与三态判定 | 多迹分数融合 → 未见异常 / 无法判定 / 疑似 | W6 |
| 证据链留痕 | 哈希链 + 案件库（SQLite） | W1 |

## 设计原则（硬线）

1. **确定性**：同一输入 + 同一版本 → 同一输出（随机种子、模型版本、配置全部锁定）
2. **可留痕**：每次分析生成不可篡改的证据链记录，可回溯校验
3. **三态判定**：不做非黑即白结论，保留「无法判定」态
4. **可评测**：所有能力先在评测协议内定义指标，再写实现（见 `doc/02-评测协议.md`）

## 快速开始

> W1 完成后补充。预期入口：

```bash
python -m forensics.cli analyze <图片路径>
```

环境依赖（W1 锁定版本）：
- Python 3.10+（venv）
- pip 依赖见 `requirements.txt`
- 系统依赖：`exiftool`（Debian/Ubuntu：`sudo apt install libimage-exiftool-perl`）
